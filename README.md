## 🌌 What is VOIDLING?

**VOIDLING** is an autonomous desktop lifeform simulation and sci-fi containment station designed specifically for Windows 11. Instead of another mundane utility, VOIDLING turns your desktop into a living cosmic anomaly chamber.

Your organism—**Zero**—is a procedurally simulated bio-mechanical creature rendered at **60 FPS** using inverse kinematics and verlet physics. It breathes, tracks your cursor with dynamic pupil dilation, responds elastically to physical petting, and evolves across 5 transcendent evolutionary tiers based on how you feed, zap, train, and mutate it.

## 🚀 How to Run & Build

### Development Mode
```bash
# Install dependencies
npm install

# Start Vite dev server + Electron desktop app
npm run desktop:dev
```

### Direct Standalone Desktop Run
```bash
# Build the application
npm run build

# Launch with Electron
npm start
```

### Standalone Windows Executable (.exe)
```bash
# Package portable unpacked Windows executable
npm run pack

# The runnable Windows desktop app is created at:
# release/win-unpacked/Voidling Anomaly.exe
```
